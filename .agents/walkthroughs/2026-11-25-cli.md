# Walkthrough: S5 — CLI + agent surface

**Date:** 2026-11-25 · **Status:** code complete; manual pass pending (uncommitted)

## What changed

- **HTTP client** (`cli/client`): typed notes (list/show/by-path/new/update/patch/delete/move/links/backlinks), search, index, auth/me, and token endpoints; problem+json errors with status-aware `IsAuth`/`IsConflict`; `ErrUnreachable`; ETag headers; token decoding/validation shared with the server format, without importing server internals.
- **Local config** (`cli/internal/config`): TOML at `~/.config/lewnotes/config.toml` (overridable with `--config`/`LEWNOTES_CONFIG`), written atomically with `0600`. `LEWNOTES_SERVER` and `LEWNOTES_TOKEN` override stored values.
- **Commands:** `login` (interactive masked paste via `stty`, plus `--server … --token-stdin --json`), `logout [--revoke]`, `whoami`, `config get|set`, `note list|show|new|append|edit|rm|mv|links|backlinks`, `search`, `index status|rescan`, `skills print|install`, `completion bash|zsh|fish`, `version`, and `help`.
- **Ref resolution:** exact ULID → exact path → unique path suffix → unique title; ambiguity exits `3` with candidates. `note append` uses PATCH with `If-Match`; `note edit` opens `$VISUAL`/`$EDITOR` and preserves the edited temp file on a `412`.
- **Agent contract:** every command supports `--json` (`{ok,data,warnings,error}`), list commands support `--json=lines`, exit codes are `0/1/2/3/4/5/6`, and `help --json` is generated from the same catalogue as human help.
- **Skill and completion:** `cli/skills/lewnotes-cli/SKILL.md` ships embedded; `skills install --dir` writes it under `lewnotes-cli/SKILL.md`.
- **Web dependency:** added `/settings/tokens` (list, create with one-time display, revoke) and a `Tokens` link in the sidebar footer. Without it the pasted-token login had no source.

## How to test manually

1. Open `/settings/tokens`, create a token, and copy it.
2. `cd cli && go run ./cmd/lewnotes login --server http://localhost:8080` and paste it (or pipe it with `--token-stdin`).
3. Try `whoami`, `note list --json`, `note show "Kitchen"`, `search garden`, `note append`, `index status`, and `skills install`.
4. `LEWNOTES_SERVER=… LEWNOTES_TOKEN=… bash cli/testdata/scripts/agent.sh "Kitchen"` exercises the scripted path (requires `jq`).

## Limits / next

- `--keyring` is not implemented; tokens live in the `0600` config file or the environment.
- Completions are static top-level command names, not per-flag completion.
- `--open` is best-effort and untested here (no browser).
- The interactive masked prompt uses `stty` on Unix; on Windows it falls back to visible input. TUI (S9) will reuse the client/config but is not started.
